ToyTalker の前払いポイント（以下「ポイント」）の購入と利用に関する決まりです。2026年11月3日版（試験提供中。内容は販売開始前に見直します）。

ポイントについて

  • ポイントは、ToyTalker の会話・読み上げなどのサービス利用に充てる前払いの対価です。1ポイント＝1円（税込）として、利用のたびに使った分だけ残高から差し引かれます。
  • ポイントは ToyTalker のサービス以外には使えず、現金や他の財産的価値と交換することはできません。
  • 残高が0以下になると、ポイントを追加するまで会話と読み上げは止まります。
  • ポイントの残高と利用状況はアプリの「利用状況」と購入ページで確認できます。

有効期限

ポイントは、最後にポイントを使った日（または購入した日）から1年間有効です。1年間ご利用がない場合、残高は失効します。ご利用があるたびに期限は延びます。

返品・返金・キャンセル

  • デジタルコンテンツの性質上、購入後の返金・キャンセルは原則としてお受けできません。
  • 例外として、お買い間違いで、その購入の後に一度もポイントを使っていない場合に限り、購入から14日以内に support@zakicorp.com までご連絡いただければ、購入を取り消して返金します。
  • 当方の障害によりポイントが正しく差し引かれなかった・減ってしまった場合は、返金ではなく同額のポイントを残高に加えて補います。

自動で買い足す設定（オートチャージ）

  • オートチャージは、残高がお客様の決めた額（100円 / 300円 / 500円）を下回るたびに、登録したカードでお客様の決めた額（500円 / 1,000円 / 3,000円）のポイントを自動で購入する設定です。申し込みは任意です。
  • 1か月（日本時間の暦月）に自動で購入する合計には、お客様の決めた上限（1,000円 / 3,000円 / 5,000円 / 10,000円）があります。上限に達したその月は自動では購入しません。1回の購入から1時間は続けて購入しません。
  • お支払いは、残高が条件を下回ったときに、その都度、登録したカードに請求します（確認の画面は出ません）。領収書は Stripe からメールでお送りします。
  • 条件・金額・上限を変えるときは、変更後の内容に同意のうえ、カードを登録し直していただきます。止めるときは購入ページの「止める」でいつでも止められ、止めた後の自動購入はありません。購入済みのポイントはそのまま使えます。
  • カードの期限切れや残高不足などで購入できなかったときは自動購入を止め、購入ページでお知らせします。カードを登録し直すと再開します。チャージバック（カード会社への支払い異議）があったときは自動購入を止め、該当するポイントを残高から差し引きます。
  • 自動で購入したポイントの有効期限と返金の扱いは、上記の各項と同じです。
