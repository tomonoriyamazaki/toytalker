プライバシーポリシー

ZakiCorp（以下「運営者」）は、音声AIおもちゃ「ToyTalker」とそのアプリ（以下「本サービス」）で取り扱う情報について、以下のとおり定めます。

1. 取得する情報

アカウントの情報

Google または Apple でログインしたときに、各社から次の情報を受け取ります。

  • メールアドレス（Apple で「メールを非公開」を選んだ場合は Apple が発行する転送用アドレス）と、それが確認済みかどうか
  • 名前（各社が提供する場合）
  • 各社のアカウントを識別する番号

パスワードは受け取りません。

音声と会話の内容

  • 話しかけた声: 文字に変換するため、音声認識サービス（Soniox）へ直接送ります。運営者のサーバーには録音を保存しません。
  • 会話の文章: 声を文字にしたものと、キャラクターの返答の文章を保存します。会話の流れを保つため、また不具合の調査とサービスの改善のために使います。
  • 声の登録（任意）: キャラクターの声として自分の声などを登録する機能を使った場合、登録した録音を音声合成サービスへ送り、声の特徴を表すデータを作って保存します。

機器と利用状況の情報

  • おもちゃの機器番号、機器の名前、選んだキャラクターと声などの設定
  • アプリとおもちゃのソフトウェアの版、要求ごとの処理時間やエラー
  • 利用量（文字数・処理量）と、それにかかった費用
  • 接続元の国（国名だけ。IP アドレスは運営者のログに保存しません）

2. 利用目的

  • 本人の確認と、アカウントと機器・設定の結び付け
  • 話しかけた内容への返答（音声認識・文章の生成・音声合成）
  • 不具合の調査、不正な利用の防止、サービスの改善
  • 利用量と費用の計算
  • お問い合わせへの対応

広告には使いません。取得した情報を販売しません。

3. 外部のサービスへの送信

本サービスは次の外部サービスを使って動いています。各サービスへは、それぞれの処理に必要な情報だけを送ります。多くは日本国外（主に米国）の事業者です。

用途事業者送る情報
サーバー・データ保存・ログインAmazon Web Services（東京リージョン）本サービスのすべての情報
ログインGoogle、Appleログインの手続き
音声認識Soniox話しかけた声
返答の文章の生成Google（Gemini）、OpenAI、Anthropic のうち設定したもの会話の文章、キャラクターの設定
音声合成Google、OpenAI、ElevenLabs、Cartesia、Fish Audio、さくらインターネット、運営者自身の音声合成サーバーのうち設定したもの返答の文章。声の登録を使った場合は登録した録音
ウェブ検索Brave Software返答に検索が必要なときの検索語

法令に基づく場合を除き、これら以外の第三者へ個人情報を提供しません。

4. Google から受け取る情報の扱い

Google のログインで受け取る情報（メールアドレス、名前、アカウントの識別番号）は、ログインと本人の確認のためだけに使います。本サービスによる Google API から受け取った情報の利用と他のアプリへの移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

5. お子さまの利用について

本サービスはお子さまが話しかけて使うおもちゃです。アカウントの作成、機器の登録と設定は保護者が行ってください。保護者は、お子さまの声と会話の文章が上記のとおり処理されることに同意したうえでご利用ください。お子さまの名前などの個人情報を、会話のなかで話さないようお伝えいただくことをおすすめします。

6. 保存期間と削除

アカウントの情報、会話の文章、設定は、アカウントの削除をご依頼いただくまで保存します。アカウントと関連する情報の削除、または保存している情報の開示・訂正・利用停止をご希望の場合は、ログインに使ったメールアドレスから下記の連絡先へご連絡ください。本人であることを確認のうえ、対応します。

障害に備えたバックアップには、削除後も最大35日間情報が残り、その後自動で消えます。

7. 安全管理

通信は暗号化し、保存する情報はアクセスできる者を必要最小限に限っています。外部サービスの鍵は暗号化して保管しています。

8. 改定

このポリシーを改定するときは、このページで告知します。大切な変更は、アプリなどで分かるようにお知らせします。
