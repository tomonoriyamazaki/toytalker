# ToyTalker

子供向け音声AIおもちゃ。話しかけると、好きなキャラクターの声で返事をしてくれる。

## 特徴

- **応答約2秒**: STT→LLM→TTSを全区間ストリーミングでつなぎ、最初の音声チャンクが生成され次第再生を開始。サーバーレス（AWS Lambda）構成のまま体感レイテンシを最小化
- **相槌**: メインの応答を生成している間に「そうだね〜」などの短い繋ぎ応答を先に返し、会話のテンポを保つ
- **ボイス・キャラクター切替**: TTSプロバイダーをプラガブルに切替可能（OpenAI / Google / Gemini / ElevenLabs / FishAudio / ずんだもん / 自前クローンボイス）。キャラクターの人格プロンプトもDBで管理
- **スタンドアロン動作**: ESP32-S3搭載の専用基板、おもちゃ単体でWiFi経由でAWSと直接通信（設定ではスマホが必要）

## しくみ
https://github.com/user-attachments/assets/177e0598-6c0a-4d14-9477-36d719003d13

```
[スマホアプリ / ESP32] ── 音声 ──> Soniox STT（直接WebSocket接続）
        │                              │ テキスト
        │                              v
        │<── 音声ストリーム ── Lambda（LLM → TTS ストリーミング）
        │<── 繋ぎ応答 ─────── Lambda（相槌）
```

- STTはLambdaを経由せず、一時キーを使ってクライアントからSonioxへ直接接続（ボトルネック回避）
- LLM→TTSは直列ストリーミングで、生成しながら順次音声化・再生
