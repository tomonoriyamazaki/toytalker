## v0.2 からの変更点（3つ）

| Ref | v0.2 | v0.3 | 理由・注意 |
|---|---|---|---|
| **MK1** | SPH0645LM4H-1-8（I2S、6パッド、生産終了） | **SPH0655LM4H-1-8**（Knowles Cornell II、**PDM**、5パッド、LCSC C22376158） | 0645 は DigiKey で Obsolete。ランドパターンが違う（列間 1.675 / 行間 0.822 / ポート中心から下段パッド中心まで 1.252（データシートの 1.513 はパッドの縁まで）、パッド 0.725×0.522、GNDリング Ø1.025/1.625）ので Knowles データシート Rev C から新フットプリント `MIC_SPH0655LM4H-1` を起こし、JLCPCB（EasyEDA）の C22376158 のフットプリントとパッド位置・寸法が一致することを確認済み（EasyEDA 側は GND リングが幅 0.07mm の線になっていて使えない）。ポート穴は **Ø0.65**（v0.2 の 0.5 から変更。データシート推奨 0.6〜1.0、EasyEDA と同じ）、I2S の WS 線（GPIO33）が不要になり未接続に。**ファームは PDM 受信に書き換えが要る**（PINMAP.md）。2軍の Goertek SD18OB261-060（C2895290）はピン・ランドパターンとも同一で BOM 差し替えだけで載る |
| **R8** | 470Ω（約1.1mA） | **1.5kΩ**（約0.33mA、1/3） | LED をさらに暗く。KT-0805W の順方向電圧は 2.6〜3.0V @2mA（Kento データシート）なので 3.3V 駆動では (3.3−2.8)/R。v0.2 の「約2.8mA」は Vf=2V の仮定で、実際は約1.1mA（0.6〜1.5mA）だった。1.5kΩ で 0.2〜0.47mA（Vf のばらつき分）。もっと暗くするなら 2.2kΩ（約0.23mA）。細かい調整はファームの PWM（`ledc`）でもできる |
| **S1** | MSK12C02G15-B（ノブ 1.5mm、本体高 1.45mm） | **ALPS SSAJ110100**（v0.1 で使った品。本体高 0.7mm、ノブ 1.3mm、LCSC C160863） | v0.1 のフットプリント `SW_SSAJ110100` を流用（ノブ側のシルクだけ消した）。基板上辺（y=12）に本体の端をぴったり合わせ、ノブは 1.3mm 外へ出る。配線は EN 方式のまま: **C=PWR_EN、2=V_SYS、1=GND**（v0.1 と同じ C–2 で ON）。**ケース側の掛かり代は要再設計**（ノブの高さが 1.45→0.7mm、突き出しが 0.5→1.3mm） |

## パッケージサイズの使い分け

サイズ表記: **0402** = 1.0×0.5mm / **0603** = 1.6×0.8mm（インチ由来の呼び名。メートル表記だと1005/1608でKiCadのフットプリント名はこちら）

| 種類 | サイズ | 理由 |
|---|---|---|
| 抵抗 全部(R1〜R14, TH1/TH2) | **0402** | 抵抗のサイズは**発熱**で決まり、値は無関係。R8 は 1.5kΩ 化で 0.2mW 未満 |
| コンデンサ 0.1µF (C6/C7/C8) | **0402** | 小容量は小さい体積で作れる |
| コンデンサ 10〜22µF (C1〜C5, C9) | **0603** | 容量は物理体積が必要。0402の10µFは高価な上、電圧がかかると実効容量が大きく落ちる(DCバイアス特性)ため0603が定石 |

※C10/C11(0.1µF)は v0.2 と同じく 0603 のまま（0402 への統一は未実施）。

## 設計の状態（2026-11-08）

- **発注済み（2026-11-08 22:22）**: JLCPCB 注文 W2026110821225257（PCB Y11-10808084A、PCBA SMT026110861471）。5 枚、2層 1.0mm 緑、**無鉛 HASL**（v0.2 の有鉛から変更。実装のはんだは v0.2 から鉛フリー）、1oz、レジストカバー、最小ビア 0.3mm、PCBA 標準・トップ面・部品配置の確認なし。合計 $160.72（送料 DHL $17.80）。出荷予定 11/12。**発注後の確認で分かったこと**: JLCPCB の配置プレビューのずれは JLC の原点・向きの定義の差で、`FT Position Offset` / `FT Rotation Offset` を 7 部品に入れて根治（全部品ぴったり一致を確認）。U1・U2・U4 は v0.2 まで向きが違っていて JLC のエンジニアが直していた。
- **到着後に実機で見ること**: マイクの録音（ファームの PDM 化が先。PINMAP.md）、LED の明るさ（1.5kΩ で v0.2 の 1/3）、スイッチの ON の向き（C–2 閉で ON の想定）と操作感・ケースの掛かり代。
- **何を変えたか（基板）**: U1（BQ25185）の放熱パッド下のビア 2 個を穴 0.2/ランド 0.4 → **穴 0.3/ランド 0.5** に（JLCPCB の「穴 0.3mm 未満かつビア径 0.4 以下は追加料金」を避ける。基板上の穴は 0.3 以上だけに）。MK1 のフットプリント差し替え（原点は v0.2 と同じ (26.1, 30.574)。DATA・CLOCK・+3V3 の配線の先端だけ新パッドへ付け替え、SELECT は裏面ベタGNDへのビア 1 個で落とす。GPIO33 の配線・ビア 2 個は削除）。S1 を `SW_SSAJ110100` に差し替え（原点 (17.5, 13.25)、180°。V_SYS / PWR_EN / GND の 3 本を新パッドへ付け替え）。R8 の値。ほかの部品と配線は v0.2 のまま。
- **ERC**: 0件。**DRC**（ゾーン再充填後、回路図との照合つき）: 20件で、内訳は v0.2 と同じ既知のもの（U4 BGA のマスク橋渡し 11、J1 シールドの基板端 0.48mm 2、J1 シルク 2、U1/U3 のライブラリ不一致 2、U1 放熱穴のネット未定義 2、S2/U3 シルク重なり 1）＋ MK1 の音孔まわりのマスク開口が NPTH と重なる注意 1（v0.2 と同じ描き方で、意図どおり）。未接続パッド 0。スピーカー音抜き穴（参照名なしの 9 個）は「回路図に無い」と出るが v0.2 からある。
- **発注前に必ず**（[マイコン](../../../docs/mcu.md) の「発注前チェック」）: KiCad で開いて 3D ビューア（MK1 と S1 は 3D モデル未割当。v0.2 も同じ）、**原寸紙テスト（SSAJ の実物をノブの出代 1.3mm で確認）**、JLCPCB の DFM。製造ファイルは `production/` に出力済み（2026-11-08、Fabrication Toolkit を CLI で実行。bom.csv は v0.2 と MK1・R8・S1 の 3 行だけ違い、positions.csv は S1 の位置と角度だけ違う。ガーバーの zip は git に入らないので、発注前に [マイコン](../../../docs/mcu.md) のコマンドで出し直す）。JLCPCB へは zip・bom.csv・positions.csv の 3 つを上げる。**全部品の LCSC 番号を回路図と基板の `LCSC Part` 項目に入れた**（v0.2 の注文で実際に選んだ番号。R8 の 1.5kΩ だけ新規に Basic の 0402WGF1501TCE = C25867）ので、bom.csv は全行に番号が入り、JLCPCB 側で部品を選び直す作業は不要。部品を変えたら `LCSC Part` も直す。
- **ケース**: スイッチの高さと出代が変わる（上記）。
- **ファーム**: PDM 化が必要（PINMAP.md）。v0.3 基板に v0.7 ファームをそのまま入れても録音できない。
- **このフォルダに無いもの**: `resources/`（部品の元データ）と v0.2 の発注出力 `production/`・原寸 PDF・設計の経過文書は v0.2 フォルダに残してある。
