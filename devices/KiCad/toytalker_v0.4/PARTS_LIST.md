## v0.3 からの変更点

| Ref | v0.3 | v0.4 | 理由・注意 |
|---|---|---|---|
| **U3** | ESP32-S3-MINI-1-N4R2 | **ESP32-S3-WROOM-1-N16R8**（C2913202） | フラッシュ 16MB・PSRAM 8MB（8 線）。18.0×25.5×3.1mm、縦置きでアンテナは基板の上辺。GPIO35〜37 は PSRAM が使うので配線しない。ビルドは `PSRAM=opi`・`FlashSize=16M`（MINI 機と同じ .bin は動かない） |
| **SP1** | HC-1.25-2PWT（MX1.25） | **SM02B-SRSS-TB**（JST SH 2P、C160402） | 小さくするため。差し口は基板の内側向き。1 = OUTP、2 = OUTN。固定用のパッド 3・4 はどこにもつながない |
| **R3** | 13kΩ（充電電圧 4.2V） | **100kΩ**（**4.1V**） | USB を挿したままでの電池の劣化を抑える。入力の上限は 1100mA のまま（BQ25185 データシート表 6-1）。使える容量は 1 割ほど減る見込み |
| **R4** | 620Ω（充電 484mA） | **1kΩ**（**300mA**） | 充電中の発熱と電池への負担を減らす（充電電流 = 300 / R）。充電時間は約 1.6 倍 |
| **R8** | 1.5kΩ | **10kΩ** | LED をさらに暗く（約 0.05〜0.07mA）。v0.3 の試験機で PWM 15% 相当に決めた |
| **R10・R11** | 470kΩ ×2 | **100kΩ ×2** | 電池の分圧。比は 1/2 のままで、計算式は変わらない。常時の電流は約 4.5 → 21µA |
| **C10・C11** | 0603 | **0402** | 0.1µF を 0402 に統一 |
| **U4** の GAIN | 未接続（9dB） | **GND**（12dB） | 隣の玉（C2 = GND）へ直結。効くかは実機で確認 |
| **U1** のシンボル | ピン 11 まで | **放熱ビア 12・13 を足した** | 基板の放熱ビア 2 個が「回路図から基板を更新」で GND から外れないように |
| ピン割当 | - | 全面的に変更 | [PINMAP.md](PINMAP.md)。アンプの BCLK と WS は配線の都合で入れ替えた（GPIO9 = WS、GPIO10 = BCLK） |

## パッケージサイズの使い分け

サイズ表記: **0402** = 1.0×0.5mm / **0603** = 1.6×0.8mm（インチ由来の呼び名。メートル表記だと1005/1608でKiCadのフットプリント名はこちら）

| 種類 | サイズ | 理由 |
|---|---|---|
| 抵抗 全部(R1〜R14, TH1/TH2) | **0402** | 抵抗のサイズは**発熱**で決まり、値は無関係 |
| コンデンサ 0.1µF (C6/C7/C8/C10/C11) | **0402** | 小容量は小さい体積で作れる |
| コンデンサ 10〜22µF (C1〜C5, C9) | **0603** | 容量は物理体積が必要。0402の10µFは高価な上、電圧がかかると実効容量が大きく落ちる(DCバイアス特性)ため0603が定石 |
