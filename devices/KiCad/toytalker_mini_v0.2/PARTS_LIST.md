## v0.1からの削除
- R5 (10kΩ TS/MR固定抵抗) → TH1に置き換え
- 旧J2/旧SP1 (JST SH) → ZH / MX1.25に変更
- 旧S1 (SSAJ110100) → MSK12C02G15-Bに変更
- V_SYS_SWネット → EN方式化により廃止

## プレフィックス順サマリ
- **J**: J1 USB-C / J2 バッテリー(ZH)
- **U**: U1 BQ25185 / U2 AP2112K / U3 ESP32-S3-MINI-1 / U4 MAX98357A
- **S**: S1 電源スライド / S2 機能 / S3 Boot
- **R**: R1,R2=5.1k(CC) R3=13k(ILIM) R4=620(ISET) R6=10k(EN) R7=10k(ボタン直列) R8=470(LED) R9=100k(PWR_ENプルダウン) R10,R11=470k(残量分圧) R12,R13=100k(STATプルアップ) R14=10k(温度分圧)
- **C**: C1,C2=10u(VBUS/VBAT) C3,C4=22u(V_SYS) C5=22u,C6=0.1u,C8=0.1u(+3V3) C7=0.1u(EN) C9=10u(V_SYS アンプ) C10,C11=0.1u(ADC)
- **TH**: TH1 充電保護 / TH2 基板温度 (同一品NCP15XH103F03RC)
- **他**: D1 LED / MK1 マイク / SP1 スピーカー
