## A. ネット名の整理(先にやると後工程が読みやすい)

- [ ] A2: U3のENピンのネット `Net-(U3-EN)` → **`ESP_EN`**(ESP32のリセット。R6/C7はそのまま)
- [ ] A3: 新ネット **`PWR_EN`** を作る(B工程で使用。ESP_ENとの混同注意 — 別物!)

## B. 電源セクション(EN方式化 + アンプV_SYS直結)

- [ ] B1: S1を電源経路(V_SYS→V_SYS_SW)から切り離す
- [ ] B2: U2(AP2112K)の**VINをV_SYSに直結**。C4(22uF)は部品そのまま、ネットをV_SYSに(VIN直近デカップリングとして残す)→ これで `V_SYS_SW` ネットは消滅
- [ ] B3: U2の**ENをVINから切り離し、`PWR_EN`ネットに**接続
- [ ] B4: S1(新部品)の配線: **common→PWR_EN、片側→V_SYS、反対側→GND**(ON=EN High / OFF=EN Low)
- [ ] B5: **R9(100kΩ・新規)** をPWR_EN–GND間に(スイッチ接触不良時にOFF側へ倒す保険)
- [ ] B6: U4(MAX98357)の**VDDを+3V3→V_SYSに**。C9(10uF)もV_SYS側(アンプVDD直近)へ
  - ※AMP_SDへの外付けプルダウンは**不要**(SD_MODEに内部100kΩ内蔵、確認済み)

## C. I2S分離 + GPIO変更(U3まわり)

- [ ] C2: U4(アンプ)BCLK: GPIO4 → **GPIO10**
- [ ] C3: U4 LRC: GPIO3 → **GPIO11**
- [ ] C4: U4 DIN: GPIO5 → **GPIO12**

- [ ] C6: 変更なし確認: MIC_BCLK=GPIO4 / MIC_DATA=GPIO9 / AMP_SD=GPIO6 / LED=GPIO8 / BUTTON=GPIO7

## D. 新規回路

- [ ] D1: 電池残量分圧: **VBAT → R10(470k) → [GPIO1] → R11(470k) → GND**、**C10(0.1µF)** をGPIO1–GND間(ADC1_CH0、WiFi中も測定可)
- [ ] D2: 充電ステータス: U1の**STAT1→GPIO13、STAT2→GPIO14**、各々 **R12/R13(100k)** で+3V3へプルアップ(STATはオープンドレインのため必須)
- [ ] D3: LED減光: **R8を47Ω→150Ω**(仮値。実機で明るさ見て調整)
- [ ] D4: 充電温度保護の有効化: **R5(固定10kΩ)を撤去し、TH1=NCP15XH103F03RC(C77131)をTS/MR–GND間に**。補正抵抗不要(β25/85=3434K≒TI要求3435K、BQ25185データシート§7.3.9で裏取り済み)。高温/低温時にBQがハードウェアだけで充電停止
- [ ] D5: 本体温度の可視化: **+3V3 → R14(10kΩ) → [GPIO2] → TH2(NCP15XH103F03RC) → GND**、**C11(0.1µF)** をGPIO2–GND間(ADC1_CH1)。ファームで温度計算しアプリ/[STATS]へ
  - ※TS共用は不可(TSはBQ内部バイアスの私有ノード。モードで電圧が変わり、外部分圧は保護閾値を狂わせる)
