# v0.2 レイアウト設計書

> **このファイルの役割: 「何と何が繋がるか、どこに置くべきか」。** 手動配置のための地図。値はPARTS_LIST.md、GPIOはPINMAP.mdが正。
> 進め方: **①この流れを見て配置 → ②配置に合わせて最寄りピンを選ぶ → ③配線**（ピンは後決め。ESP32-S3はGPIOマトリクスでほぼ全信号を任意ピンに振れる）

## 1. 信号の流れ（これだけ見て配置できる版）

```
■ 電源の幹線(太線0.5〜0.6mm)
USB J1 ─VBUS→ C1 → U1充電IC ←VBAT→ C2 → J2電池
                     U1 ─V_SYS→ C3 → ┬→ C4 → U2 LDO → C5 ─+3V3→ みんなへ
                                     └→ C9 → U4アンプ(V_SYS直結)

■ 電源ON/OFF(細線でOK)
S1スイッチ ─PWR_EN→ U2のENピン   (R9=100kをPWR_EN-GND間のどこかに)

■ 音声出力(この順に一直線に置くと配線が素直)
U3 ══I2S 4本══> U4アンプ ──OUT± 2本──> SP1コネクタ → スピーカー

■ 音声入力
MK1マイク ══I2S 3本══> U3    (+3V3とC8がMK1のそばに必要)

■ 監視(全部細線・遅い信号)
J2のVBAT ── R10 ─┬─ R11 ── GND     ┬の点 → U3のADCピンへ (C10はピン側)
+3V3 ── R14 ─┬─ TH2 ── GND        ┬の点 → U3のADCピンへ (C11はピン側)
U1のSTAT1/2 ──→ U3へ2本            (R12/R13=100kで途中どこかから+3V3へ)

■ 操作・表示(細線)
S2ボタン ── R7 ── U3へ1本
S3ブート ── U3のGPIO0へ1本(固定)
U3から1本 ── R8 ── D1 LED ── GND

■ その他
J1のD+/D- ── U3のGPIO19/20へ2本(固定)
+3V3 ── R6 ─┬─ U3のENピン(右下角に固定)   C7も┬の点に
U1まわりの設定部品: R3(ILIM), R4(ISET), TH1(TSピン直結)
```

## 3. 配置のルール（守らないと性能・製造に響くものだけ）

1. **パスコンは相棒ピンから2mm以内**: C6→U3の3V3ピン / C9→U4のVDD / C5→U2出口 / C4→U2入口 / C1,C2,C3→U1 / C8→MK1
2. **ADCは「コンデンサだけピン側、抵抗・サーミスタは源流側」**(C10/C11をU3の近くに)
3. **TH2は熱源(U3・U4)から遠く**、電池の近く
4. **アンテナ帯(x46.2〜52, y12〜29.5)**: 銅・部品・配線すべて禁止(設定済みキープアウト)
5. **裏面(B.Cu)はベタGNDの聖域**: 部品は置かない。裏面配線ジャンプはDC/低速のみ・短く・モジュール直下(x30.8〜51.8)に入れない・この文書の台帳に記録
6. **スピーカー円(中心41.75,41.75 r10)の内側**: 部品NG(音抜き穴と実物スピーカーの領域)
7. **基板端から銅0.5mm**、部品の専有領域(courtyard)は重ねない(0402同士は中心間1.9mm以上、0603は3.0mm以上)
8. 大電流ペアは短く: J2⇔U1、U4⇔SP1

## 7. 手順

1. 保存 → Claudeがファイルから機械チェック(重なり・基板端・アンテナ帯・パスコン距離・通り道の幅)

3. 配線(幹線→信号→ベタGND) → フルDRCゼロ → 原寸紙テスト → 発注
