# ToyTalker 製品化 認証チェックリスト（日本市場・STマーク目標）

対象: 自作ペンダント型ToyTalker（ESP32-S3 + LiPo + スピーカー/マイク + WiFi/BLE、子供向け）。
作成: 2026-09-09。認証は法規制が絡むため、本チェックリストは方向性の整理であり、確定情報は各所管団体・試験機関に確認すること。

## A. おもちゃ本体の安全 — STマーク【本丸】

発行: 一般社団法人 日本玩具協会。完成品を第三者機関（CERI等）に出して試験。3本柱:

- [ ] 機械的安全性: 誤飲（小部品）・尖り・強度。**ペンダント型は紐/ストラップの誤飲・首まわりの窒息リスクが要注意**
- [ ] 可燃安全性: 筐体・部材の燃えにくさ
- [ ] 化学的安全性: 鉛・可塑剤など有害物質の移行
- [ ] 電池は筐体内に固定し露出させない設計（ST基準の電池要件）

## B. 電波 — 技適【ESP32があるため必須】

- [ ] **ESP32-S3-MINI-1モジュールが日本の技適を取得済みか確認** → 済みならモジュール認証を流用でき、製品側の追加取得は不要
- [ ] 自作アンテナ・別モジュールに変更すると自分で取り直しになる → 技適済みモジュールを使い続ける

### B-2. Bluetooth の申告（Bluetooth SIG）【技適とは別。BLE を使う製品を売るなら必須】

2026-11-18 に調べた範囲（料金は公式の料金表 https://www.bluetooth.com/fee-schedule/ で確かめる）。

- Bluetooth を使う製品を売る会社は、Bluetooth SIG に入会し（Adopter は会費無料）、製品を申告して料金を払う。**Adopter で1設計あたり $12,000**（2026 年に $11,040 から値上げ）。
- 認証済みのモジュール（ESP32-S3）をそのまま使えば追加の試験は要らないが、自社製品としての申告と料金は要る。
- ロゴや「Bluetooth」の名前を出さなくても、技術を使えば対象。
- 売上の小さい会社向けの割引（$2,500）は 2020 年 2 月に新規受付を終了。代わりの制度は見つかっていない。
- 同じ設計を含む2製品目以降は無料という記述がある（フォーラムの情報。未確認）。
- Amazon は出品時に申告の ID を求めることがあるらしい（未確認）。
- [ ] **方向（2026-11-18）: 売る本体では BLE を使わない**（設定は SoftAP、保護者が見る・書くは暗号化つきの中継。[本体の記憶](device-memory.md) の「BLE をやめる」、ロードマップ45）。ファームから BLE を外した版を売る本体に入れる。

## C. 電池の安全書類【部品選定に直結】

- [ ] 使用する電池モデルの **UN38.3 試験報告書**を業者から入手（名義より、使用モデルと一致していることが重要）
- [ ] **IEC 62133** 証明の要否を **日本玩具協会/試験機関に確認**（ST必須かは未確認。「あれば有利」までが確実、「無いと不可」とは言えない）
- [ ] **電池の体積エネルギー密度（Wh/L）を業者に確認** → PSE（菱形/電池）対象判定用。304040 は約385Wh/L で 400Wh/L 未満＝対象外の可能性が高いが**400にギリ近いため実測値で要確認**。3×40×45mm・500mAh なら計算上は約343Wh/L で境界から離れる

### 電池の仕入れ先との確認（2026-11-19 時点。まだ決まっていない）

相手は Alibaba の Shenzhen Bihuade Technology（ブランド名 Liter energy battery）。やり取りは Alibaba のメッセージに残っている。

**分かったこと**

- **304040（3×40×40mm・500mAh。今の基板と外装の前提）には認証が無い**（業者の回答）。UN38.3 が付くのは **3×40×45mm・500mAh** のほう。厚さは同じで、平面の長辺が 5mm 伸びる。
- **認証があるのは 0.5C 品だけ**（充電 250mA・放電 250mA まで）。1C にするには専用の保護回路が要り、その認証は無い（業者の回答）。
- 304040 の仕様書（受領済み。雛形の使い回しで、認証の証拠にはならない）: 線は UL1571 AWG28・50±5mm、標準のコネクタは「Jst1.25」（Molex PicoBlade 互換の 1.25mm ピッチ。基板の J2 は JST ZH の 1.5mm なので挿さらない）、保護回路あり（NT1718B + 8205A）、NTC あり。過充電保護が 4.200V と書いてあり、誤記かどうか未確認。

**基板への影響**

- **充電**: 基板は 500mA 充電の設定（R4 = 620Ω）で、0.5C 品では規格を超える。0.5C 品を使うなら R4 を変えて 250mA にする（満充電までおよそ倍の 2.5〜3.5 時間）。
- **放電**: 再生中の電流は見積もりでアンプ 100〜300mA + Wi-Fi 80〜120mA（ロードマップ19。実測は無い）。最大音量で連続 250mA を超えるなら 0.5C 品は使えない。

**業者に頼んである仕様**（45mm 品のサンプル10個の見積もり）: コネクタ JST ZHR-2（1.5mm ピッチ・2ピン）、赤黒の AWG28・50mm、NTC の線なし、保護回路つき、1番ピンが赤（＋）・2番ピンが黒（−）。ZH の2ピンに決まった極性は無いので、製造前に写真か図面で確かめ、届いたらテスターで確かめてから挿す。

**残っていること**

- [ ] **本体の電流を実測する**（今の 304040 と今の基板でよい。USB を抜き、電池の赤い線にテスターを 10A レンジで直列に入れ、待機・ふだんの音量・最大音量の再生中の平均を読む）。最大音量で 250mA を超えるかで下の分かれ道が決まる
- [ ] 業者から受け取る: 45mm 品の仕様書、UN38.3 試験サマリーと MSDS（型番・寸法・保護回路つきの状態が一致しているか見る）、コネクタの極性の写真か図面、見積もり
- 認証つきでもっと容量の大きい型番として業者が出したのは **5×40×50mm・1300mAh（実際の厚さ 4.7mm）** の1つだけ。0.5C で 650mA なので電流は足りるが、厚さが 1.7mm 増え、計算上は約 510Wh/L で **400Wh/L を超えて PSE の対象になりうる**。重さも増える。予備の案
- [ ] 分かれ道: 250mA 未満なら 45mm 品で進め、WROOM 版の基板と外装を 40×45mm に合わせる（J2 は電池の線が出る辺に置く。線の長さは組んでから詰める）。超えるなら、容量の大きい認証品にするか、1C で UN38.3 が出る別の業者を探す

## D. PSE 整理

- **充電器（ACアダプター）**: 菱形PSEが必要だが、**自社で充電器を売らず市販PSE済みアダプター運用なら、自社取得は不要**
- **電池そのもの**: 上記Cの通り、単電池400Wh/L以上でPSE対象。候補は境界付近のため実測要確認

## E. 誰がやるか（切り分け）

- **自分**: 技適済みモジュールの確認 / 電池書類の入手 / 誤飲・紐まわりの設計配慮 / 電池の体積エネルギー密度確認
- **専門家・試験機関**: ST試験の実施 / PSE該当性の最終判定 / IEC62133要否の回答
- **パートナー企業（AI抱き枕側）**: 抱き枕版の安全はパートナー(寝具メーカー)の品質・コンプラチームが主導（可燃・熱安全は寝具メーカーの本領）
