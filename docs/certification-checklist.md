# ToyTalker 製品化 認証チェックリスト（日本市場・STマーク目標）

対象: 自作ペンダント型ToyTalker（ESP32-S3 + LiPo + スピーカー/マイク + WiFi/BLE、子供向け）。
作成: 2026-09-09。認証は法規制が絡むため、本チェックリストは方向性の整理であり、確定情報は各所管団体・試験機関に確認すること。

## A. おもちゃ本体の安全 — STマーク【本丸】

発行: 一般社団法人 日本玩具協会。完成品を第三者機関（CERI等）に出して試験。3本柱:

- [ ] 機械的安全性: 誤飲（小部品）・尖り・強度。**ペンダント型は紐/ストラップの誤飲・首まわりの窒息リスクが要注意**
- [ ] 可燃安全性: 筐体・部材の燃えにくさ
- [ ] 化学的安全性: 鉛・可塑剤など有害物質の移行
- [ ] 電池は筐体内に固定し露出させない設計（ST基準の電池要件）

## B. 電波 — 技適【ESP32があるため必須】

- [ ] **ESP32-S3-MINI-1モジュールが日本の技適を取得済みか確認** → 済みならモジュール認証を流用でき、製品側の追加取得は不要
- [ ] 自作アンテナ・別モジュールに変更すると自分で取り直しになる → 技適済みモジュールを使い続ける

## C. 電池の安全書類【部品選定に直結】

- [ ] 使用する電池モデルの **UN38.3 試験報告書**を業者から入手（名義より、使用モデルと一致していることが重要）
- [ ] **IEC 62133** 証明の要否を **日本玩具協会/試験機関に確認**（ST必須かは未確認。「あれば有利」までが確実、「無いと不可」とは言えない）
- [ ] **電池の体積エネルギー密度（Wh/L）を業者に確認** → PSE（菱形/電池）対象判定用。現行候補は約385Wh/L で 400Wh/L 未満＝対象外の可能性が高いが**400にギリ近いため実測値で要確認**

## D. PSE 整理

- **充電器（ACアダプター）**: 菱形PSEが必要だが、**自社で充電器を売らず市販PSE済みアダプター運用なら、自社取得は不要**
- **電池そのもの**: 上記Cの通り、単電池400Wh/L以上でPSE対象。候補は境界付近のため実測要確認

## E. 誰がやるか（切り分け）

- **自分**: 技適済みモジュールの確認 / 電池書類の入手 / 誤飲・紐まわりの設計配慮 / 電池の体積エネルギー密度確認
- **専門家・試験機関**: ST試験の実施 / PSE該当性の最終判定 / IEC62133要否の回答
- **パートナー企業（AI抱き枕側）**: 抱き枕版の安全はパートナー(寝具メーカー)の品質・コンプラチームが主導（可燃・熱安全は寝具メーカーの本領）

- 経産省 リチウムイオン電池PSE FAQ: https://www.meti.go.jp/policy/consumer/seian/denan/lithium_faq.html
