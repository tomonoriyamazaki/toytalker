# 意図的に先送りしている項目

コードから読み取れない「やらないと決めた理由」と、着手時の設計メモ。着手したらここから消す。

## 読み上げモード（`toytalker-tts-only-lambda` / `app/components/ReadAloud.tsx`）
- 長文分割: 単一TTS呼び出しのみ。OpenAIの4096字などプロバイダー上限を超えるとエラーがそのままアプリに出る。
- 日英分割読み: 単一ボイスで一括読み。
- Androidのバックグラウンド再生: フォアグラウンドサービスが必要。現状アプリはiOSのみ提供。
- iOSのバックグラウンド再生は `app.json` に `UIBackgroundModes: ["audio"]` を追加済みだが、EASのネイティブ再ビルドが必要でOTA更新では反映されない。

## ユーザー認証
- 現状の `owner_id` はアプリ初回起動時のランダムUUIDで、認証なし。iOSはキーチェーンに保存、Androidはアンインストールで消える（許容済み）。
- 本格認証はCognito + Sign in with Appleを想定。実装時はJWT検証をLambda内のJWKSキャッシュでローカル完結させ、音声パイプラインにネットワーク認証を挟まない（会話レイテンシ維持）。既存 `owner_id` のデータは初回ログイン時にアカウントへ紐付け移行する。
- 導入時の設計の出発点は [認証導入時の設計メモ](auth-design-notes.md)（owner_id の扱い、ESP32、トークン検証の場所、合成時の持ち主チェック）。
