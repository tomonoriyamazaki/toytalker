## A. 物の安全と法規

[認証チェックリスト](certification-checklist.md) に無い分だけ。

- **対象年齢の線引き**: 3歳未満向けは子供 PSC マーク（2025年12月からの国の規制）、6歳未満向けは食品衛生法（口に触れるおもちゃ）の対象になり得る。「対象年齢◯歳以上」で要る試験が変わる（未確認）。
- **首にかける紐**: 強く引くと外れる留め具にする。外装（[外装 README](../devices/enclosure/toytalker_mini/README.md)）の設計に入れる。
- **充電器**: AC アダプタを同梱しない（USB ケーブルだけ。同梱すると PSE の対象）。
- **表示**: 技適番号を本体か箱に、警告（誤飲・電池・紐）を取扱説明書に。
- **PL 保険**（生産物賠償責任保険）: 個人でも製造者として責任を負う。売り始めと同時に入る（下の F）。

## B. API 事業者の規約（最初に確かめる）

公表すれば済む話ではなく、規約が許さなければ事業者を替えるしかない。**時期: 販売の直前まで待たず、LLM や声まわりに次に手を入れるときに先に済ませる**（結果しだいで主の LLM（いまは Gemini）を替えることになり、後になるほど手戻りが増える。2026-11-15）。対象は `privacy.html` の表の事業者: Soniox、Google（Gemini）、OpenAI、Anthropic、ElevenLabs、Cartesia、Fish Audio、さくらインターネット、Brave。

事業者ごとに確かめること:

1. **子どもが使うサービスに組み込んでよいか**。Gemini API の追加規約に「18歳未満向け、または18歳未満が使いそうなサービスに組み込まない」趣旨の条項があったという記憶がある（**未確認**。事実なら主の LLM を Vertex AI 経由か他社へ替える）。
2. **送った内容が学習に使われるか**（有料の API は既定で使わない事業者が多いが、無料枠は別のことがある）。
3. **データ処理の契約（DPA）があるか、データを置く国はどこか**（C の「海外への提供」の根拠になる）。

- **会話ログの保持期間**: **決定（2026-11-15）: 本番系は保存しない**（[先送り項目](deferred-items.md) の「会話ログの保持期間」、ロードマップ7(d)）。保存をやめても、海外の事業者へ送ることと事業者側の保持は残る（B と上の項目）。

## F. 事業の形（開業届・法人化・保険）

2026-11-16 に相談。中身は Claude の知識からで、**制度・判例の原文は未確認**（金額も記憶から）。決める前に税理士・保険会社・相談窓口で確かめる。

- **いま**: 法人でも個人事業でもない。お金を受け取っていない試用の間は何も要らない。
- **方針の案（未決定）**: 知らない家庭へ本当に売るなら法人にする。持っているだけで費用がかかるので、**「売る」と決めてから作る**。途中で個人から法人へ替えると Stripe・Apple の開発者アカウント・各 API の契約の名義変更が要るので、売るなら最初から法人で始める。少数の直販だけ先に個人事業（開業届 + バーチャルオフィス + PL 保険）で始め、広く売る前に法人にする順番も成り立つ。

### 段階ごとに要るもの

| 段階 | 要ること |
|---|---|
| 今（知人への試用、無料） | 何も要らない |
| ポイントや本体を売り始める | 少なくとも開業届。特商法の表記、Stripe の本番審査（[原価と課金の考え方](pricing-and-cost-model.md) 11.8）。PL 保険 |
| 知らない家庭へ広く売る（Amazon など）、または同意のうえで会話を保存する | 法人化と保険（PL + 情報漏えい）を済ませておく |

### 法人にする理由

1. **責任に上限を作る**: 個人事業は賠償が個人の財産まで及ぶ。法人は原則として会社の財産まで。一番大きいのは物の事故（子ども向け・電池入り・首にかける）で、情報漏えいより金額が大きくなり得る。
2. **会社と契約しやすい**: DG のような会社は、個人より法人のほうが契約を結びやすい。
3. **「ZakiCorp」の名前**: 会社でない者が会社と誤解される名前を使うことを会社法が禁じている。「Corp」が当たるかは未確認。個人事業で開業届を出すなら先に確かめる。法人にすれば問題は消える。

住所を出さないことは理由にならない（個人事業でもバーチャルオフィスを使え、特商法の表記も「請求があれば開示」で住所・電話番号を省ける。販売者名の本名は出る。Amazon は本人確認でその住所の書類や郵便の受け取りを求められることがある）。

### 法人にしても残ること

- **払うのは保険**: 法人は責任に上限を作るだけ。賠償を実際に払うのは保険なので、法人化より保険のほうが先に効く。
- **代表者の責任はゼロにならない**: 危険を知っていて放置したような重い落ち度があれば個人にも及び得る。安全の試験（[認証チェックリスト](certification-checklist.md)）を通しておくことがここでも守りになる。
- **費用**: 設立は合同会社で 6〜10 万円ほど、株式会社で 20 万円台。赤字でも毎年 7 万円ほどの税金と、決算の手間。一人で始めるなら合同会社で足りる。

### 保険

- **PL 保険**（物の事故の賠償）: 個人事業でも法人でも要る。売り始めと同時。
- **情報漏えいの保険**（サイバー保険・個人情報漏えい保険。賠償と調査費用）: 会話を保存しない間は優先度が低い。同意のうえで保存する形を足すときは先に入る。
- 情報漏えいの賠償の見当: 日本の裁判では1人あたり数千円〜数万円の例が多い（総額は人数で決まる）。賠償より、調査・国への報告・本人への通知の手間が重いこともある。

### 会話を保存する形との関係

- 個人情報を保持できるかは、法人かどうかでは決まらない（個人でも法人でも、同意と安全管理があれば保持できる）。法人化で変わるのは、説明のしやすさ（「会社が預かる」）と責任の上限。
- **同意のうえで会話を保存する形（親がアプリで ON にした家庭だけ、短い期限で自動削除、親が見られて消せる、本番は CMK）を足すのは、法人化と保険がそろってから**。それまでは「本番系は保存しない」のまま（[先送り項目](deferred-items.md) の「会話ログの保持期間」「親が会話を見る機能」）。足すなら自分用の本番（`prd`）から。西川さん向け（`prd-nk`）は DG が望んだときだけ。

### 決めること・確かめること

- 売る時期と、法人にする時期（合同会社か株式会社か）
- 勤め先があるなら、開業届や法人の代表になることが就業規則に触れないか
- 個人と法人のどちらが税金の面で得か（売上の見込みが出たら税理士に聞く）
- PL 保険の加入先と保険料（本体の原価計算に入れる）
- 「ZakiCorp」を個人事業の屋号に使えるか

## G. 他社と比べたときの売り（2026-11-23）

商品ページと保護者向けの説明で前に出す点。比べた相手は Tuya（中国。おもちゃは自分で売らず、通信モジュール・クラウド・会話エンジンを各ブランドへ卸す。載っている製品は Fuzozo、BUBU the Owl、Walulu など）。

**売りにする点**

| 点 | ToyTalker | 相手側の事情 |
|---|---|---|
| 会話を溜めない | 会話の文章は本番系で保存しない（C）。録音も保存しない。運営の資源は AWS 東京 | Tuya は「地域ごとのデータセンターに置き、地域の外と共有しない」と説明しているが、音声会話の扱いは公式ページに書かれていない。中国企業なので中国のデータ安全法の対象になり得るという指摘がある。2026 年秋は中国製 AI おもちゃの会話の漏えい（別会社で約 1,300 万件）や、米国の議員による調査の要請、量販店の掲載取り下げが続いた |
| 子供が使う前提で作る | 使うのは子供、買って設定して支払うのは保護者、という分け方で作る。本体だけで話せ、残高が無くなったら本体が子供に一言伝えて保護者に知らせる | Tuya の仕組みは大人向けの相棒（Fuzozo）にも子供向けにも使われ、子供向けの安全設定を入れるかは売る会社しだい。英国では、安全設定を入れずに幼児向けとして売られたウサギのおもちゃが不適切な返答をし、政府と Amazon・eBay が調べている（2026-11、報道 1 件） |
