## いまの状態（2026-11-15）

- **きっかけ**: 「Amazon などで販売する場合、API の利用やデータの保存は利用者が用意するのか、サービスで提供するのか」というコメント。
- **答え（今の作り）**: すべてサービス側で提供する。API の鍵は運営が持ち、費用は前払いポイント（[原価と課金の考え方](pricing-and-cost-model.md) 11）で回収する。データは運営の AWS（東京）に置き、録音は保存せず、会話の文章を保存する（`web/site/privacy.html`）。
- **下の項目はどれも未着手**。中身は 2026-11-15 に Claude の知識から並べたもので、**条文・各社の規約・Amazon の規約の原文はまだ確かめていない**。確かめたら「確認済み（日付・出典）」に書き換える。
- 物の認証（ST マーク・技適・電池の書類・PSE）は [認証チェックリスト](certification-checklist.md) が持つ。お金まわりの宿題（特商法の表記・Stripe の本番審査・消費税・資金決済法）は [原価と課金の考え方](pricing-and-cost-model.md) 11.8 の「売り始める前の宿題」が持つ。ここには重ねて書かない。

## A. 物の安全と法規

[認証チェックリスト](certification-checklist.md) に無い分だけ。

- **対象年齢の線引き**: 3歳未満向けは子供 PSC マーク（2025年12月からの国の規制）、6歳未満向けは食品衛生法（口に触れるおもちゃ）の対象になり得る。「対象年齢◯歳以上」で要る試験が変わる（未確認）。
- **首にかける紐**: 強く引くと外れる留め具にする。外装（[外装 README](../devices/enclosure/toytalker_mini/README.md)）の設計に入れる。
- **充電器**: AC アダプタを同梱しない（USB ケーブルだけ。同梱すると PSE の対象）。
- **表示**: 技適番号を本体か箱に、警告（誤飲・電池・紐）を取扱説明書に。
- **PL 保険**（生産物賠償責任保険）: 個人でも製造者として責任を負う。入るか、いつ入るかを決める。

## B. API 事業者の規約（最初に確かめる）

公表すれば済む話ではなく、規約が許さなければ事業者を替えるしかない。**時期: 販売の直前まで待たず、LLM や声まわりに次に手を入れるときに先に済ませる**（結果しだいで主の LLM（いまは Gemini）を替えることになり、後になるほど手戻りが増える。2026-11-15）。対象は `privacy.html` の表の事業者: Soniox、Google（Gemini）、OpenAI、Anthropic、ElevenLabs、Cartesia、Fish Audio、さくらインターネット、Brave。

事業者ごとに確かめること:

1. **子どもが使うサービスに組み込んでよいか**。Gemini API の追加規約に「18歳未満向け、または18歳未満が使いそうなサービスに組み込まない」趣旨の条項があったという記憶がある（**未確認**。事実なら主の LLM を Vertex AI 経由か他社へ替える）。
2. **送った内容が学習に使われるか**（有料の API は既定で使わない事業者が多いが、無料枠は別のことがある）。
3. **データ処理の契約（DPA）があるか、データを置く国はどこか**（C の「海外への提供」の根拠になる）。

## C. 個人情報と子どものデータ

- **海外の事業者へ送ること**: 個人情報保護法では、保護者の同意（送り先の国名とその国の制度を示す）か、相手が日本法と同等の措置を取る契約のどちらかが要る（未確認）。今のポリシーは事業者名と「主に米国」まで。**足りないかもしれないもの**: 初回セットアップで保護者が同意を押す画面、事業者ごとの国名。
- **会話ログの保持期間**: 無期限のまま（[先送り項目](deferred-items.md) の「会話ログの保持期間」、ロードマップ7(d)）。売る前に決める。
- **売る国**: 米国の13歳未満には COPPA（保護者の検証可能な同意）、EU には GDPR がかかる。日本だけで売るなら対象外。シアトルの配布機は知人への試用。
- **日本の法改正**: 子どもの個人情報に保護者の同意を求める改正が議論されていた。現状を確かめる。

## D. 売る場所

- **方針の案**: まず自社サイトなどで少数を直販し、初期設定で詰まる所と問い合わせの量を見てから Amazon に出す（Amazon のレビューは後から消せない）。未決定。
- **Amazon で要るもの**（未確認）:
  - リチウム電池の書類（UN38.3 の試験サマリー・SDS）。仕入れ先から出るかを先に確かめる。出ないと Amazon の倉庫からの発送（FBA）に入れられない
  - 商品コード（JAN コード = GS1 への事業者登録、または商標を取ってブランド登録）
  - 手数料（月額・販売手数料・配送と保管）を本体の原価計算に入れる
  - 出品者情報として氏名・住所・電話番号が公開される
  - **購入者を自社サイトへ誘導する販促は禁止**。ポイントの購入ページへの案内が「製品を使うための設定」として許されるかを規約の原文で確かめる

## E. 買った後の体験

- **商品ページに書くこと**: 別に利用料（ポイント）が要る、スマホのアプリとログインが要る、2.4GHz の Wi-Fi が要る、対象年齢、会話の文章が保存され海外の事業者へ送られること。
- **開けてから初めて話すまで**: 本体を買った人は残高0から始まる（特典は配らない。[原価と課金の考え方](pricing-and-cost-model.md) 11.1）。セットアップの途中で購入へ案内する流れは未決定。
- **返品**: 戻った本体の登録を外す手順、残ったポイントの扱い、もう一度売れるか。
- **サービスの終了**: サーバーが止まると本体は動かない。最低限の提供期間と、終了時の残高の扱いを決めて書く。
- **サポート**: 1人で受けられる問い合わせの量に合わせて、最初に売る数を決める。
