# 外装の作り方（3D プリントから射出成形へ）

外装（[外装 README](../devices/enclosure/toytalker_mini/README.md)）を売る数だけ作る方法の、決めたことと道筋。形そのものの状態は外装 README が持つ。ここは「どう作るか」だけを書く。

## いまの状態（2026-11-27）

- **方針**: 型と成形は外に出さず、まず自分でやる。理由は、型の設計と成形の勘所を自分に残すため（外注先と話せるようになる）。
- **済んだこと**

  - ミスミに個人事業主として登録した（屋号は空欄、氏名で登録）。

  - つまみ・蓋・本体の形を、型で抜ける形に直す（下の「形を直す所」）。
  - TIB FAB の無料の期限（受賞の特典。2027 年 2 月ごろまでと記憶）と、その後の会員の扱いを聞く。

## 道筋

| 数量 | 型 | 成形 |
|---|---|---|
| 〜数十個 | なし | 3D プリント（P2S、ABS） |
| 〜数百個 | SR200 か自前の CNC で、アルミの板 2 枚の型 | 手動の成形機 |
| 数百〜数千個 | 工場の規格に合わせた入れ子、または卓上の自動機用の型（自前の CNC か外注） | 工場、または卓上の自動機 |
| 数千個以上 | 工場が作る | 工場 |

- 進む順は、P2S で形を詰める → SR200 で練習 → つまみの型 → 蓋の型 → 本体の型。削る量が少なく、失敗しても軽い物から。
- 自前の CNC（候補は Makera Carvera Air、オリジナルマインド KitMill AST200 / RZ）を買うのは、SR200 で何枚か削って、力・精度・段取りの不満が実感で分かってから。型の精度を決めるのは CNC なので、自動機へ進む道は成形機より先に CNC の側から開く。
- 工場に成形を頼むなら、**型を作る前に工場と話す**。自分の判断で作った型は、工場の機械に載らないので受けてもらえない。受けてもらえる形は、工場の規格の入れ子を作って渡すか、データを渡して型ごと作ってもらうかの 2 つ。
- 手動機用の板の型は自動機では使えない（材質ではなく作りの問題。取り付けの土台・押し出しピン・冷却の水路が無い）。持ち越せるのは、型向けに直した形のデータと、打って分かった不良の出方。

## 材料

- 売る個体は PLA にしない。55〜60℃ で柔らかくなり（夏の車内で歪む）、落とすと欠けて尖った破片が出る。試作は PLA のままでよい。
- 3D プリントで売る分は ABS（P2S は囲い付き。熱と落下に強く、アセトンで表面を整えられる）。寸法は ABS で縮み方が変わるので、切り替えたら隙間の試験片を刷り直す。
- 3D プリント品で認証を受けるなら、試験に出した個体と同じフィラメントの銘柄・色・刷る向き・設定で作り続ける（[認証チェックリスト](certification-checklist.md) の A）。
- **成形の樹脂は PP を本命にする（2026-11-27）。ABS も同じ型で打って、手に取って最終決定する**。PLA はペレットでも使わない。PP を本命にした理由は、子供向けの実績（食器・哺乳瓶・おもちゃ。可塑剤もビスフェノール A も使わない）、割れても尖った破片になりにくいこと、力の弱い手動機（0.5 トン）でも本体が入る見込みがあること。売る分は、寒さでも割れにくい種類（ブロックコポリマー）を選ぶ。PP にしたときに確かめる所は、蓋の爪の保持（子供が電池に触れられないこと）、握ったときのたわみ、蓋の反り、つまみが引っ張って外れないこと。
  - PP: 流れやすく乾燥が要らないので、最初の練習はこれ。爪が折れにくく、つまみの滑りが良く、力の弱い機械でも入りやすい。縮みが大きい（1.5〜2%。ABS は 0.4〜0.7%）ので嵌合の寸法は合わせ直しで、平らな蓋は反りやすく、薄い壁はたわむ。接着・印刷が付きにくい。
  - ABS: 硬くて寸法が安定し、つやが出る。80℃ で 2〜4 時間の乾燥が要り（湿っていると出口で弾ける。安全のためでもある）、PP より流れにくい。
  - 売る分は材料を 1 つに固定し、その縮みに合わせて型の寸法を決める。
- **難燃 ABS**（UL94 V-0）は、電池が発火したときに外装が燃え広がるのを抑えるが、電池の火そのものは止められない。難燃剤（臭素系とアンチモンの組み合わせが多い）が化学的な試験で不利になる恐れがあり、手動機では筒の中で焼けやすい。練習と試作には使わない。売る分をどうするかは試験機関に聞く: 電池入りのおもちゃの外装に難燃グレードは求められるか、難燃剤の成分で試験に引っかかる物はあるか。発火への備えは電池の側（保護回路、書類の出るモデル、充電の温度制限、押しつぶさない構造）が主。

## ペレット

- 量と値段: 本体・蓋・つまみで約 7.1cc（ABS で約 7.5g）。通り道と失敗の分を足して 1 台 10〜15g。小分けは 500g で 1,500 円前後（1kg あたり約 3,000 円）なので、1 台 30〜45 円。25kg 袋なら 1kg あたり数百円（目安。未確認）。
- 買える所（2026-11 に調べた範囲。品揃えと在庫の細部は未確認）
  - [オリジナルマインド](https://www.originalmind.co.jp/products/inari-f06/options): INARI のオプション品として PP（黒）250g 690 円、PS（透明）250g 860 円、PE（白）250g 820 円など。ABS は無い。
  - [Nature3D](https://nature3d.net/materials/): 射出成形用を個人に売ると明記。練習用の PP の候補。
  - [AvalonTech](https://avalontech.jp/product/fs06taiyaki/): 成形機 TAIYAKI のページに、ABS（黒 1,480 円、透明 500g 1,680 円、耐熱グレー 500g 1,490 円）、PC、EVA、シリンダ洗浄剤が並ぶ。成形機なしでペレットだけ買えるかは未確認。
  - [標準試験片オンラインショップ](https://standard-testpiece-onlineshop.com/page/resin-pellets)、モノタロウ、楽天（手芸用の詰め物や洗浄用が混ざるので、「射出成形用」と銘柄の記載を見る）。
- 売る分は、メーカーと銘柄（グレード名）が分かり、SDS が出る、射出成形用のグレード（繊維なし）に固定する。試し打ちは気にしなくてよい。
- 色は、色付きのペレットを買うのが確実。無着色に色の素（マスターバッチ）を混ぜる方法は、手動機が樹脂をかき混ぜないので筋やまだらになる。塗装は、剥がれて口に入る恐れがあるのでしない。
- 透明な ABS は配合の違う別グレード（薬品に弱め、傷が目立つ）。PC は 280〜300℃ が要り手動機では難しい。耐熱 ABS は流れにくい。
- 樹脂や色を替えるときは、前の樹脂を筒から押し出し切る（洗浄剤を使う）。

## 型を削る機械: KitMill SR200（TIB FAB）

公式の仕様（オリジナルマインド。生産終了品、後継は CL200）。

- ストローク X 356 / Y 206 / Z 73.6mm、載せられる材料の高さ 29.4mm。TIB FAB の機材一覧は加工領域の Z を 25mm としている（施設側の制限かは講習で聞く）。
- 主軸 35W。回転数は 5,600、3 段プーリーがあれば 3,400 / 5,600 / 10,000。プログラムからは変えられない。
- 刃の軸は 3 / 3.175 / 4 / 6mm のどれか（付いている主軸で決まる）。
- 送りの上限は毎分 1,000mm。精度の目安は ±0.1mm（位置合わせのピン穴は現物合わせ）。
- 動かすソフトは EdingCNC（Windows、無償。機械なしでもプログラムの読み込み確認ができる）。Fusion のポストは標準ライブラリの「KitMill series ORIGINALMIND」。
- 削る条件の出発点（同じ 35W の CL200 で A7075 を削った公式の例）: 直径 2mm の刃、切り込み 0.2mm、送り毎分 300mm、10,000 回転。深さ 5mm で 25 段、型 1 枚に数時間。
- 固定は捨て板に両面テープが基本。強く削るならクランプ。
- 手動機用の板の型には足りる。自動機用の型（厚いブロック、押し出しピンの穴、合わせ面の精度）には力と精度が足りない。

**講習で聞くこと**: 付いている主軸の軸の太さと刃が備え付けか、プーリーの有無、アルミ（A7075、80×80×10 / 20mm）の持ち込みと固定方法、施設が決めている高さの制限、1 回の予約で使える時間、売る製品の型を作ってよいか（規約の利用目的は試作と実証）。

## 型の設計の決まり（オリジナルマインドの金型設計ルール）

- 材質は A7075、厚みは片側 20mm 以上（面積が広ければ 30mm 以上）。
- 抜き勾配は壁 1°、穴の内側 3°。内側の角は刃の半径の丸みが残る（最小 R0.5）。肉厚は 1〜3mm。
- 樹脂の入口は、側面から入れる場合 直径 4〜6mm。空気の逃げ道の溝を設ける。
- 型の上下は M5 か M6 のボルトで締める（取付ピッチ 50mm 以内）。細い押し棒の圧力が部品の面積全体にかかるので、バイスで挟むだけでは型が開いてバリが出る。
- 板は 80mm 角に統一する（くぼみの周りに 15mm 以上の余白。ピン穴・ボルト穴・固定の場所）。INARI M06 の上限（高さ 91mm、厚さ 70mm）に収まる。
- 型は上下で形が違う。片方は部品の外側の形のくぼみ、もう片方は内側の形の出っ張り。
- アルミを削る前に、Fusion の CAM の再生と、型そのものを P2S で刷って上下が合うかを確かめる。

## 形を直す所

- **本体**: 側面のスイッチの窓、USB の口、蓋の爪の受けは、上下に開く型では抜けない。穴を合わせ目まで伸ばして切り欠きにするか、穴なしで打って後から開ける。
- **つまみ**: スイッチのノブをはさむ指 2 本が各 1.0×1.2mm で、型にすると直径 0.8mm 以下の刃が要る。板・舌・指が別の向きに伸びている。型向けに単純な形へ直す。
- **蓋**: 形は単純。43×44mm のくぼみを 0.2mm ずつ削るので時間がかかる。
- **LED を見せる（案。未決定）**: 基板の白 LED（D1）の真上だけ、壁を内側から彫って 0.4〜0.6mm にし、透かして見せる。範囲は直径 3〜5mm（広いと樹脂が入らない）、LED との距離は 1〜3mm、周りを筒状のリブで囲んで光の漏れを止める。穴も別部品も要らず、消灯時は何も見えない。黒の外装では通らない。型の前に、白の ABS で薄さ 0.4 / 0.6 / 0.8mm の試験片を P2S で刷って見え方を確かめる。v0.4 の LED の抵抗（10kΩ）は今の外装に合わせて暗くしてあるので、薄い壁ごしでは足りない恐れがある（抵抗を小さめにして PWM で絞るほうが後から合わせやすい。v0.4 は未発注）。

## 知っておくこと

- **Fusion は個人用ライセンス（商用利用不可）**。売る製品の設計に使うなら、売る前に商用へ切り替える。個人用は CAM に制限がある（早送りが使えないなど。型を削ること自体はできる）。
- 屋号に「Corp」を使うと、会社でない者が会社と誤解される名前を使うことを禁じた会社法に触れる恐れがある。法人化までは取引先に出す屋号にしない。
- 成形機の安全: 保護メガネ、耐熱の手袋、綿の長袖、粒の乾燥、台への固定、換気、子供の手が届かない場所。CNC は逆に手袋をしない（巻き込まれる）。
